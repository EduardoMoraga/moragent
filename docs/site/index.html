One crew of AI coding agents, in real panes, with memory.

MORAGENT turns any repo into an agentic project: Claude Code, Codex, Antigravity and Pi work side by side, hand tasks to each other through a bus on disk, and remember what they decided — in markdown your Obsidian vault can read.

npm i -g moragent

then cd your-repo && mora — Node ≥ 18, zero npm dependencies, MIT.

Why MORAGENT

Several agents is easy. One crew is the hard part.

Getting agents from different vendors to share work, remember decisions and stay out of each other's files. MORAGENT is a thin executive layer on top of the multiplexer you already use.

60-second tour

Real commands, nothing hidden.

Every read command takes --json and every command works without a TTY — so the lead agent can drive all of this itself.

mora init --preset trio --goal "Online coffee shop"
mora doctor
mora plan "Stripe checkout, admin, receipts"
mora spec status
mora up
mora dispatch backend "Orders API" --spec <slug>
mora dispatch frontend "Checkout screen"
mora wait T-0001 T-0002
mora board
mora memory add "Orders use UUIDv7" --tier canonical
mora brain link
  1. Set upA five-question wizard (or flags) writes .moragent/ and one managed block in AGENTS.md, CLAUDE.md, GEMINI.md.
  2. Checkdoctor lists Node, each CLI with its version, multiplexers and your vault — with the one-line fix for anything missing.
  3. Planplan sizes the idea (S/M/L/XL), recommends a crew and creates the first spec; spec status shows its slug and phase.
  4. Runup opens one pane per role; dispatch writes a task envelope and types one line into the right pane. Add --dry-run to rehearse.
  5. Integratewait blocks until tasks finish; results become episodic memory; durable decisions go canonical.

How it flows

Markdown on disk is the source of truth.

No server, no daemon, no database. Any agent from any vendor can read and write .moragent/ — and so can you.

lead→ mora dispatch→ panes→ mora done→ memory→ Obsidian
crew

Roles, not prompts

Each role has a mission and a CLI. Presets solo, duo, trio, squad. Swap with mora crew set.

bus

Tasks as files

queued → sent → running → done | failed | blocked. Workers close with mora done or mora block.

memory

Three layers + skills

canonical decisions, episodic results, transient scratch that expires, and skills synced to every CLI.

sdd

Phases the binary decides

explore → propose → spec → design → tasks → apply → verify → archive, derived from the files. mora spec next.

brain

Obsidian second brain

mora brain link puts .moragent/ in your vault. Frontmatter, [[wikilinks]] and a generated Home.md.

plugin

Claude Code & Codex

The repo is a plugin for both: lead, worker, spec and memory skills that call mora.

Autonomy & safety

Workers that don't stall — without handing over the keys.

A worker that stops to ask permission in a pane nobody is watching blocks the crew. Each role gets an autonomy level in crew.<role>.autonomy.

auto · default

Edit and report back

Edits in the repo plus mora, node, npm test, git status/diff. Codex keeps its workspace sandbox; Claude asks for anything else.

full · --yolo

No prompts, no sandbox

mora up --yolo for one session, or mora config set crew.<role>.autonomy full. Only in a disposable environment.

ask

The CLI's own prompts

Nothing is pre-approved. Headless runs are never ask, because nobody could answer them.

automatic memory

Every session leaves a note

mora init (or mora sync --hooks) installs a Claude Code SessionEnd hook and Codex notify: one episodic note per session, no LLM, with secrets redacted.

FAQ

Coming from a chat window?

You don't need to know tmux or any agent jargon to start.

Do I need to know tmux?

No. Inside Orca or herdr panes open by themselves. With only tmux installed, MORAGENT creates the session and prints the one command to attach. With nothing, agents run headless and you follow the board.

Is it one AI or several?

Several independent agent CLIs, each in its own pane and signed in with its own account. MORAGENT gives them a shared to-do list and a shared memory.

Does it send my code anywhere?

MORAGENT itself makes no network calls. The agent CLIs you run talk to their own providers, exactly as they do without MORAGENT.

What does it cost?

MORAGENT is free and MIT-licensed. Each agent CLI uses your existing subscription or API key.

I only have Claude Code.

That works — every role can use the same CLI. mora doctor tells you what's missing and how to install it.

Can I undo it?

Everything lives in .moragent/ plus a marked block in AGENTS.md / CLAUDE.md / GEMINI.md. Delete those and you're back where you started.
