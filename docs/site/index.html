Connect what you already have

No MORAGENT account. No server. No proxy.

The app detects subscription CLIs already logged in on your machine and can also run native API loops with your own keys or local Ollama. Credentials stay local in ~/.moragent/credentials.json or environment variables.

subscription CLIs

Claude Code, Codex, Antigravity, Pi

Use vendor CLIs headlessly for subagents and orchestration. MORAGENT normalizes their streams into one in-app event format.

API providers

Anthropic, OpenAI, OpenRouter, Google

Native tool loop with project-confined read_file, write_file, edit_file, grep and bash.

local

Ollama

Run the orchestrator or workers against a local OpenAI-compatible endpoint. Useful when you want fully local execution.

Inside the app

Slash commands keep the harness under your fingers.

The native TUI is the default entry point. The older mora CLI still works for scripts, CI and external agents.

/helpShow available commands.
/loginConnect subscriptions, API keys or Ollama.
/equipoView or reassign the crew; English alias: /crew.
/orquestador <motor>Pick the orchestrator engine; English alias: /orchestrator.
/memoria [texto]Show memory or search notes; English alias: /memory.
/plan <texto>Ask for an explicit plan before running subagents.
/abrir <rol|id>Pop an agent out into Orca, herdr or tmux; English alias: /open.
/cancel · /salirCancel running work or quit; English alias: /exit.

FAQ

Coming from a chat window?

Do I need tmux, Orca or herdr?

No. MORAGENT v5 is a standalone terminal app. Multiplexers are optional and only used when you choose to pop an agent out with /open or /abrir.

Is it one AI or several?

One executive orchestrator coordinates specialized subagents. Each role can use a different subscription CLI, API model, or the same engine if that is all you have.

Does MORAGENT send my code to its own server?

No. There is no MORAGENT account, server or telemetry. Your configured providers talk directly from your machine to their own services; Ollama stays local.

What does it cost?

MORAGENT is free and MIT-licensed. You pay only for your existing subscriptions or API usage.

Can I run without initializing a project first?

Yes. In a folder without .moragent/, the TUI asks what you want to build and initializes the project inline.

Can I undo it?

Everything lives in .moragent/ plus managed comment blocks in instruction files such as AGENTS.md and CLAUDE.md. Remove those and the repo is back to its prior shape.
