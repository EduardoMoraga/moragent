# Security Policy

## Supported versions

MORAGENT 4.x receives security fixes.

## Reporting a vulnerability

Report privately to Eduardo Moraga at eduardo.moraga.o@gmail.com with:

- affected version and OS;
- reproduction steps;
- impact;
- suggested fix if known.

Do not publish exploit details until a fix or mitigation is available.

## Secrets

Never store credentials in `.moragent` memory, specs, task envelopes or issue reports. Use your platform secret manager or local ignored files.
