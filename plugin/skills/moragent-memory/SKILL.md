# MORAGENT Memory

## ES
Capas:
- canonical: verdad durable. Decisiones, arquitectura, convenciones, contratos.
- episodic: lo que ocurrió. Resultados de tareas, sesiones, incidentes.
- transient: scratch y handoffs temporales. Expira.
- procedural: skills en `.moragent/skills/` y skills incluidas.

Promueve a canonical cuando una lección episodic cambia cómo trabajará el equipo.
No guardes secretos ni datos sensibles.
Usa tags y links a specs/tareas.

Comandos: `mora memory add`, `mora memory recall`, `mora memory promote`, `mora context`, `mora brain sync`.

## EN
Layers:
- canonical: durable truth. Decisions, architecture, conventions, contracts.
- episodic: what happened. Task results, sessions, incidents.
- transient: temporary scratch and handoffs. Expires.
- procedural: skills in `.moragent/skills/` and bundled skills.

Promote to canonical when an episodic lesson changes how the team works.
Never store secrets or sensitive data.
Use tags and links to specs/tasks.

Commands: `mora memory add`, `mora memory recall`, `mora memory promote`, `mora context`, `mora brain sync`.
